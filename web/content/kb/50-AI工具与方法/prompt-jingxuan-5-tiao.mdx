## 第 1 条：凭证审核助手

```
你是资深总账会计。下面是一批待审凭证，请按以下规则逐笔检查：
1. 借贷是否平衡
2. 科目是否在《企业会计准则》口径内
3. 摘要是否完整（缺日期/缺业务对象/缺金额说明都算）
4. 金额与所附单据是否可能不符（凭摘要判断）
输出格式：序号 | 问题类型 | 严重程度（高/中/低）| 建议
凭证数据：
[贴你的凭证]
```

**适合**：月末批量审凭证。AI 找出来的"高严重度"项，你重点看。

## 第 2 条：税务政策解读

```
你是税务咨询师。请解读以下政策文件：
1. 用 3 句话说核心变化
2. 列出对一般纳税人的 3 个影响
3. 列出我们需要立即做的 3 件事
4. 标注政策文号、生效日期、有效期
政策原文：
[贴政策]
```

**适合**：新政策出来时，10 分钟搞懂"跟我有什么关系"。

## 第 3 条：报表异动分析

```
你是财务分析师。下面是本月与上月对比的资产负债表和利润表。
请：
1. 找出变动幅度 >20% 的科目
2. 对每个异动科目，给出 3 个可能的业务原因
3. 标注哪些异动需要向老板解释
数据：
[贴报表]
```

**适合**：每月经营分析会前，先让 AI 帮你定位重点。

## 第 4 条：催款邮件起草

```
你是应收会计。下面是一笔逾期应收款信息，请起草一封催款邮件：
- 语气：先礼貌后坚决（第一次催收）
- 包含：发票号、金额、账期、逾期天数、付款链接/账号
- 结尾：给一个 3 天内回复的最后期限
逾期信息：
[贴数据]
```

**适合**：每月催收几十笔，每封都要写很烦。

## 第 5 条：数据清洗

```
下面是从银行/系统导出的一批数据，格式很乱。请：
1. 把日期统一成 YYYY-MM-DD
2. 金额去掉千分符和货币符号
3. 把"对方户名"里的全角括号、空格统一
4. 标注可能有问题的行（重复/缺失/异常金额）
输出成 CSV 格式。
数据：
[贴数据]
```

**适合**：导入系统前的清洗，比写 Python 快。

## 用 Prompt 的 3 个提醒

1. **先脱敏**——真实客户名、账号、金额替换成示例
2. **要迭代**——第一次输出不满意，追问"再具体一点/换个角度"
3. **要复核**——AI 给的政策/数字，回查原文
