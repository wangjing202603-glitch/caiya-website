> **本节要点**：泰国付款要先扣 WHT 再到账；服务费/租金/利息/广告等不同名目税率不同（1%-15%）；不扣漏扣 = 公司补 + 罚；申报走 PND3。

## 泰国付款的逻辑跟国内反着

国内付款：签合同 100 万 → 付 100 万 → 各自申报增值税/企税。

**泰国付款**：签合同 100 万 → **付 95 万 + 扣 5 万 WHT 直接交税务局** → 收款方拿 95 万 + 凭证去抵自己税。

WHT（Withholding Tax，预扣税）的核心：**付款方有义务替税务局先扣一笔**。这是国内没有的概念，出海企业最容易踩的坑。

## 哪些付款要扣 WHT

不是所有付款都扣。常见要扣的：

| 付款类型 | 常见 WHT 税率（参考） | 说明 |
|---|---|---|
| 服务费（咨询/审计/法律） | 3% | 最常见 |
| 租金（办公/厂房） | 5% | |
| 广告费 | 2% | |
| 利息 | 1% | |
| 演讲/培训费 | 3% | |
| 国际运输 | 涉及双边协定 | 复杂，找税务师 |
| 专业服务（给海外公司） | 15% | 给非泰居民的服务费 |

**关键**：税率是参考，实际以 Thailand Revenue Code + 双边税收协定为准。给中国母公司付服务费，可能涉及中泰协定优惠税率。

## 不扣 / 漏扣的后果

如果该扣没扣：

- **税务局找付款方（你公司）补**——不是找收款方
- 加罚息 + 罚款
- 影响公司税务信用

所以出海企业财务的第一条铁律：**每笔付款过手时，先问"这要不要扣 WHT"**。

## 实操流程

### Step 1：付款前判断
付款申请单上加一个字段："是否需扣 WHT / 税率"。会计按付款类型预判。

### Step 2：付款时扣
合同 100 万服务费，扣 3% = 3 万。实际付 97 万给供应商，3 万单独申报交税务局。

### Step 3：申报（PND3）
月度申报，填 PND3 表（预扣税申报表），把本月扣的所有 WHT 汇总上报 + 缴款。

### Step 4：给收款方凭证
申报完，给供应商一份 **WHT 凭证**（扣税证明）。收款方拿这个凭证去抵他自己的应纳税额。

## 容易踩的 3 个坑

### 坑 1：以为付海外就不用扣
给中国母公司付服务费，**也要扣 WHT**（除非适用双边协定优惠）。这跟很多人直觉相反。

### 坑 2：税率记错
不同名目税率差很大（1% vs 15%）。建一张"付款类型 → WHT 税率"对照表，付款时查表不靠记忆。

### 坑 3：凭证没给
扣了税但没给收款方凭证，对方没法抵税，会回来找你扯。申报完立刻发凭证。

## AI 怎么帮你

- **建 WHT 对照表**：让 AI 按 Thailand Revenue Code 整理"付款类型 → 税率 → 申报表"
- **付款预检**：每笔付款贴给 AI，问"这要不要扣 WHT，扣多少"
- **PND3 汇总**：让 AI 把本月所有扣税明细汇总成申报草稿

但 AI 给的税率**必须**回查泰国税务总局最新规定 + 你的税务师。

## 工具化思路

我们在泰国岗位把 WHT 判断做进了**付款流程**：

```
付款申请单（含付款类型）
   ↓
工具自动查 WHT 对照表 → 标"扣 / 不扣 + 税率"
   ↓
会计确认 → 实付金额 = 合同 - WHT
   ↓
月末汇总 WHT → 生成 PND3 申报草稿
```

工具在设计中，目前用 Excel 对照表 + 人工判断过渡。

## 给出海人的话

WHT 不是"复杂"，是"反直觉"。国内财务的肌肉记忆是"付完款再算税"，泰国是"付款时就要替税务局扣"。**第一条**：把"这要不要扣 WHT"写进每次付款的反射动作。
