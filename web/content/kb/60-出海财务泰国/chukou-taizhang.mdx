> **本节要点**：出口台账跟进口对称复用；4 Sheet（订单/出运/收款/应收）；资料驱动放文件自动回填收款；EXW 条款报关费客户付。

## 出口跟进口是镜像

泰国子公司既进口（从中国母公司买料）也出口（把成品卖给海外客户）。出口的流程跟进口**对称反向**：

```
进口：合同 → 进口报关 → 到货 → 付款 → 收发票
出口：订单 → 出运报关 → 发货 → 收款 → 开发票
```

所以出口台账跟进口台账**复用同一套资料驱动 DNA**，只是字段和方向反过来。

## 4 Sheet 结构

| Sheet | 内容 | 驱动方式 |
|---|---|---|
| 1 订单主数据 | 客户、产品、数量、单价、条款 | 手工维护 |
| 2 出运记录 | 出运日、报关单、物流单 | 出运文件夹驱动 |
| 3 收款登记 | 收款日、金额、银行 | 收款回单驱动 |
| 4 应收余额 | 应收 = 订单 - 已收 | 公式自动 |

## 资料驱动：放文件自动回填

跟进口一样，文件夹按时序建：

```
出口台账/
├── 01_订单/          ← 订单确认书
├── 02_出运单证/      ← 报关单、装箱单、提单
└── 03_收款/          ← 客户汇款水单
```

把客户汇款水单放进 `03_收款/`，脚本识别客户名 + 金额 + 日期，自动回填 Sheet 3，应收余额（Sheet 4）实时更新。

## EXW 条款的关键

我们主要客户用 **EXW（Ex Works）条款**——意味着：

- **报关费、国际运费由客户承担**
- 我们只负责把货备好出厂
- 出口销售额 = 出厂价（不含国际段运费/报关费）

这点很重要：台账里的"销售额"口径要跟条款一致，不能把客户付的运费算进我们的收入。

## 收款驱动应收

出口台账的核心跟进口一样，是**应收跟踪**：

```
订单金额（Sheet1）
- 已收款（Sheet3 驱动）
= 应收余额（Sheet4）
```

每笔收款水单回填后，余额自动算。账期到期提醒（如客户 A 账期 75 天，到期未收标红）。

## 实测案例

某订单 26TY001-1：
- 出运日：5/15
- 账期：出货后 75 天（USD 结算）
- 应收到期日：7/29（系统自动算）
- 到期前 7 天系统提醒
- 收款登记驱动回填 → 应收余额自动归零

## 与进口台账的对称复用

两套台账共用：

- **同一套资料驱动引擎**（格式过滤 + 核心号提取 + 孤儿检测）
- **同一套主数据**（客户/供应商、产品、银行）
- **同一套设计原则**（5 条，见进口台账篇）

差异：

| 维度 | 进口 | 出口 |
|---|---|---|
| 主表 | 7 步 | 4 步 |
| 余额方向 | 应付（欠供应商） | 应收（客户欠我） |
| 税务 | 进口 VAT + WHT | 出口退税（如适用） |
| 收付 | 付款驱动 | 收款驱动 |

## 报关费已确认

之前一个待确认点：出口报关费谁付？已确认——**客户付**（EXW 条款）。台账按不含报关费设计。

## 你怎么用

如果你也做出海贸易台账：

1. **先画单据流转时序**——决定建几个文件夹
2. **复用资料驱动引擎**——进口出口一套 DNA
3. **注意条款口径**——EXW/FOB/CIF 销售额口径不同，台账字段要对齐
4. **收付驱动余额**——放回单/水单自动算，不要月末手工对
