> **本节要点**：母公司加价 → 子公司成本虚高、毛利虚低；还原 = 剥掉关联方加价看真实成本；转让定价要符合独立交易原则。

## 关联方加价是怎么发生的

中国母公司生产化妆品，卖给泰国子公司（关联方）。母公司不会按成本价卖——要加一笔利润。这笔加价，对泰国子公司的影响：

```
母公司成本 80 → 加价 20 → 卖给子公司 100
子公司账面：采购成本 = 100
子公司加工后卖 130 → 账面毛利 = 30（毛利率 23%）
```

但真实情况：

```
真实成本 80 → 卖 130 → 真实毛利 = 50（毛利率 38%）
```

**关联方加价让子公司的账面毛利虚低**（不是虚高，方向别搞反）。毛利率从 38% 看着像 23%。

## 为什么要还原

3 个理由：

### 1. 看子公司真实盈利
老板要看"泰国子公司到底赚不赚钱"。账面毛利 23% 是假的，还原后 38% 才是真实经营能力。

### 2. 转让定价合规
泰国税务局盯关联方交易。加价太高（把利润都留在低税地）或太低（把利润都转给关联方），都可能被认定为**转移利润**，要求补税 + 罚款。

### 3. 合并报表
集团合并报表要把关联方内部交易**抵消**（intercompany elimination）。不还原，合并数也对不上。

## 还原的方法

### 方法 1：成本加成法（最常用）
按母公司实际成本 + 合理加成率（参考独立第三方同类交易），算出"应该的"转让价。

```
合理转让价 = 母公司成本 × (1 + 合理加成率)
关联方加价 = 实际转让价 - 合理转让价
```

合理加成率参考：行业平均、独立第三方交易、成本加成惯例。

### 方法 2：再销售价格法
子公司卖给第三方的价格，倒推母公司应该卖给子公司的价格。

```
合理转让价 = 子公司对第三方售价 - 合理毛利
```

### 方法 3：利润分割法
把集团利润按各实体贡献分割。复杂，用于高度整合的关联交易。

制造业通常用**成本加成法**（方法 1）。

## 我们的实操

泰国子公司从母公司进口，台账里记两类核价：

| 类型 | 内容 | 用途 |
|---|---|---|
| 一类核价 | 直接按合同价（含加价） | 对外账务、代账 |
| 两类核价 | 合同价 + 关联方加价明细 | 内部管理账、成本还原 |

月度还原：把"关联方加价"从子公司采购成本里**剥出来**，单独入"内部利润"科目。看管理报表时用还原后成本，看对外报表时用合同价。

## 转让定价文档

泰国税务局要求关联方交易留存文档：

1. **主体文档**：集团整体业务 + 关联交易概述
2. **本地文档**：泰国子公司关联交易明细 + 定价依据
3. **国别报告**：集团全球利润 + 税负分布（大集团才需要）

文档核心：证明你的转让价**符合独立交易原则**（Arm's Length Principle）——加价率跟独立第三方交易一致。

## AI 怎么帮你

- **建加价率模型**：让 AI 基于历史数据算各品类的合理加成率
- **月度还原计算**：把进口台账贴给 AI，自动剥关联方加价、算还原后成本
- **文档草稿**：AI 帮你起转让定价本地文档草稿（主体 + 本地）

但转让定价涉及税务合规，**AI 草稿必须税务师审**。

## 给出海人的话

关联方成本还原是出海财务的**硬骨头**，也是最容易被忽略的：

- 不还原，老板看不到子公司真实盈利
- 不留文档，税务局来查没有依据
- 加价不合理，可能被认定转移利润

如果你做出海财务，第一件事是把**关联方加价的明细**从合同价里拆出来单独记——别混在采购成本里。

- 关联方加价让子公司**毛利虚低**（不是虚高）

- 转让定价要符合**独立交易原则**，留存主体/本地文档
- 两类核价：合同价（对外）+ 加价明细（内部）
