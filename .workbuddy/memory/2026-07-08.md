## 代言人偶配色审查

- 用户提出两个审查维度：1) 配色与网站调性是否搭；2) 目标受众主要是女性，是否符合女性审美
- **关键发现：配色严重不匹配**
  - 网站实际设计系统（globals.css + tailwind.config.ts）使用**暖琥珀 amber** 单一色板，品牌主色 #F09A1A
  - CSS 注释明确写了「告别冷 slate 蓝灰」「整站唯一色板」
  - 代言人偶却以**蓝色系**为主（#185FA5 / #378ADD / #0C447C），网站设计系统中完全不存在蓝色
  - 总体色彩匹配度仅约 15%（仅财务金 #EF9F27 与品牌琥珀 #F09A1A 接近）
- **女性受众适配度也偏低**
  - 蓝色在色彩心理学中偏理性/男性化
  - 矩形机器人造型偏科技/工业感，女性偏好圆润有机造型
  - 亲和力细节（腮红/蝴蝶结/大眼睛）是好的开始但比例太小
- SkillHub 上未找到专门的设计审查技能（搜索了 design review / color audit / brand consistency 等关键词）
- 建议：用网站实际琥珀色板重新设计人偶，软化造型，增强暖调和亲和力
