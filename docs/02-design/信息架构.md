## 2. 导航

### 2.1 顶栏（所有页面）

- 左：Logo（`/`，含中英文）
- 中：主导航（首页 / 知识库 / 定价 / 社群）
- 右：搜索图标（唤起命令面板）、主题切换、登录态/头像

### 2.2 侧栏（仅 KB 详情 / 分类页）

- 顶部：当前分类名 + 描述
- 中部：分类树（最多 2 级）
- 底部：最近更新 5 篇

### 2.3 底栏

- 备案信息（占位）
- 用户协议 / 隐私政策
- 商务合作邮箱
- 公众号二维码

## 3. 关键任务流

### 3.1 新用户首次访问

1. 入口：搜索引擎 → KB 详情页
2. 阅读完 → 看到"加入社群"CTA
3. 扫码加微信群 / 注册会员
4. 第二天收到周报邮件

### 3.2 试用 AI 问答

1. 在 KB 任意页 → 顶栏"问 AI"
2. 弹窗式 ChatBubble：输入问题
3. 收到答案 + 引用卡片
4. 命中 3 次后提示"今日额度用完"
5. 引导升级会员

### 3.3 付费订阅

1. `/pricing` 选择套餐
2. 跳支付（微信 / 支付宝）
3. 扫码 → 支付成功 → 回调开通
4. 自动跳回详情页解锁会员内容

### 3.4 续费

1. 邮件提醒"还有 7 天到期"
2. `/account/billing` 一键续费
3. 支付 → 自动延期

## 5. URL 规范

- 全部小写，中文用拼音（kebab-case），如 `/kb/shuiwu-yu-hegui/zengzhi-shui`
- 数字编号**不出现在 URL**，仅用于排序
- 永久重定向：文章 slug 改动 → 旧 URL 301 跳新 URL

## 6. SEO 基础

- 每个详情页：
  - `<title>` = 文章标题 - 分类名 - 站点名
  - `<meta description>` = Frontmatter 的 `description`
  - JSON-LD：`Article` + `BreadcrumbList`
- 站点级：`Organization`、`WebSite`（含 `SearchAction`）
- `sitemap.xml` 自动生成（阶段 1）
- `robots.txt` 允许抓取 KB 全部；禁止抓取 `/account/*` `/admin/*`

## 7. 性能与缓存

- 详情页：构建时 SSG + ISR（10 分钟 revalidate）
- 分类页：构建时 SSG
- 搜索页：动态（带缓存头 `s-maxage=60, stale-while-revalidate=600`）
- API：默认 `s-maxage=0`，AI 问答不缓存

## 8. 错误页

- 404：`/kb` 引导
- 500：友好提示 + 客服微信二维码
- 会员过期：跳 `/account/billing` 续费
