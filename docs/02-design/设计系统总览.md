# 设计系统总览

> 最后更新：2026-07-01 · 维护人：@设计负责人

## 1. 设计原则（5 条）

1. **清晰优先于炫技**：财务人对"一目了然"的要求高于"酷"。
2. **中文优先**：字号、行距、标点全部按中文阅读习惯调，英文/数字是次级语言。
3. **克制的留白**：参考 starglowai.com/kb 的呼吸感，但避免"空到不知所云"。
4. **暗色侧栏 + 浅色正文**：让"导航"与"阅读"在视觉上分离，降低阅读疲劳。
5. **可访问性是底线**：所有交互都有键盘可达 + 屏幕阅读器友好方案。

## 2. 设计令牌（Token）体系

三层结构：

- **基础层**（Primitive）：原始值，如 `#2D6BFF`。
- **语义层**（Semantic）：用途命名，如 `color.brand.solid`。
- **组件层**（Component）：组件专用，如 `button.primary.bg`。

**强制规则**：

- 业务代码只能引用**语义层**或**组件层**。
- 业务代码禁止出现裸色值、裸像素、裸字号。违规 PR 会被打回。
- 改色 / 改间距 → 必须改 `docs/02-design/设计令牌.md` 对应行，影响面评估后才能合入。

完整取值见 [`设计令牌.md`](./设计令牌.md)。

## 3. 组件分层

| 层 | 来源 | 说明 |
|---|---|---|
| L0 原语 | Tailwind / Radix UI | 按钮、输入框、复选框等无业务语义 |
| L1 基础 | shadcn/ui | 复制到仓库内 `components/ui/`，按需改 |
| L2 业务 | 自研 | `KbSidebar` `KbToc` `KbCard` `Paywall` `ChatBubble` 等 |
| L3 页面 | 业务拼装 | 首页、KB、详情页等，仅在 `app/` 下出现 |

详细清单与状态机见 [`组件库.md`](./组件库.md)。

## 4. 排版与栅格

- 基础栅格：8px
- 容器宽度：1280px（`max-w-7xl`）
- 文章正文最大宽度：720px（`prose` 默认值附近），过大影响阅读
- 段间距：24px（`space-y-6`）

## 5. 响应式断点

| 断点 | 范围 | 行为 |
|---|---|---|
| sm | < 640 | 单列，侧栏抽屉，TOC 折叠到顶部 |
| md | 640~1024 | 单列为主，可保留侧栏 |
| lg | 1024~1280 | 双栏，侧栏可折叠 |
| xl | ≥ 1280 | 完整三栏（导航 + 正文 + TOC） |

## 6. 暗色模式

- 默认跟随系统（`prefers-color-scheme`）
- 用户可在右上角手动切换，写入 `localStorage('theme')`
- 暗色下：
  - 背景：`ink-950`（深石板）
  - 侧栏：`ink-900`，分隔线 `ink-800`
  - 正文：`ink-50` 文字 + `ink-900` 背景
  - 代码块：`ink-950` 背景 + 浅色语法

## 7. 图标与插画

- 图标库：Lucide（与 shadcn/ui 配套）
- 不使用 emoji 作为 UI 图标
- 插画风格：扁平 + 浅描边，色板取自 `accent-*`
- 占位插画：用 `https://placehold.co/1200x630/2D6BFF/FFFFFF?text=AICaiWu`（阶段 0 调试用）

## 8. 动效

- 页面切换：180ms `ease-out` 淡入
- Hover：120ms
- 模态弹出：200ms `cubic-bezier(0.16, 1, 0.3, 1)`
- 禁用：动效通过 `prefers-reduced-motion: reduce` 完全关闭

## 9. 国际化

- 现阶段只服务中文，文案统一放在 `i18n/zh-CN.ts`（阶段 1 建立）
- 不写硬编码中文字符串到组件里（"取消"、"确定"等）
