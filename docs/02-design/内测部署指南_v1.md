# 财芽网站内测部署指南 v1

> 目标：1-2 周内测期，分享给朋友/群闭门使用，收集反馈后修，再公开上线
> 平台选择：**Zeabur**（CN 机房，对标站 starglowai 也在用）
> 创建时间：2026-07-08

---

## 一、为什么选 Zeabur

对标站 [starglowai.com](https://starglowai.com) 的部署：
- 服务器：**Zeabur**（zeabur.app 域名指向 Zeabur CN 机房）
- 域名：zeabur.app **子域名**（没买自己域名）
- 部署：Next.js 零配置，git push 几分钟上线

**对我们的好处**：
- ✅ **免 ICP 备案**（Zeabur 主体有备案，用户访问无障碍）
- ✅ **国内可访问**（CN 机房，国内打开快）
- ✅ **Next.js 零配置**（Zeabur 是 Vercel 同源，next build 自动识别）
- ✅ **免费额度够用**（个人项目小流量，5$/月 hobby 计划更好）
- ✅ **环境变量 + 自定义域名**后续都能加
- ❌ 缺点：国内访问不如自建 ECS（但内测够用，稳定后再迁）

## 三、准备步骤（用户操作）

### Step 1：建 GitHub 仓库

1. 登录 [github.com](https://github.com) → **New repository**
2. 仓库名：`caiya-website`（或你喜欢的）
3. 设为 **Private**（内测阶段别公开源码）
4. **不**勾选 Initialize with README（项目已有）

### Step 2：本地推代码

项目根 `F:\AI工具\AI财务网址搭建\` 暂不是 git 仓库（根 .gitignore 存在但无 .git）。需要先初始化并推上去：

```bash
cd "F:\AI工具\AI财务网址搭建"
git init
git add .
git commit -m "财芽网站 v1 - 内测版（46篇文章+8板块+Amber Clarity设计）"
git branch -M main
git remote add origin https://github.com/<你的用户名>/caiya-website.git
git push -u origin main
```

> **注意**：根 .gitignore 已排除 `node_modules/ / .next/ / .env*`，推上去不会带敏感文件。
> 确认 `web/.gitignore` 也存在（已确认），web/ 单独 git 库可不用管。

### Step 3：Zeabur 部署

1. 登录 [zeabur.com](https://zeabur.com) → **Sign in with GitHub**
2. **Create New Project** → **Git** → 选 `caiya-website` 仓库
3. 选 **web/** 目录作为根目录（Next.js 项目在 web/ 子目录）
4. 检测到 Next.js → **Deploy**
5. 几分钟后拿到 URL：`caiya-<hash>.zeabur.app`

### Step 4：自定义子域名（可选）

Zeabur 控制台 → Settings → **Domains** → 添加 `caiya.zeabur.app`（如果默认不是这个）

## 四、环境变量（最小集）

在 Zeabur 控制台 → **Variables** 加：

| 变量 | 值 | 必填 | 说明 |
|---|---|---|---|
| `NEXT_PUBLIC_SITE_URL` | `https://caiya.zeabur.app` | ✅ | sitemap/robots 用 |
| `APP_URL` | 同上 | ✅ | metadata base |
| `NODE_ENV` | `production` | ✅ | 强制生产模式 |

**暂不接的（内测期不需要）**：
- `AUTH_SECRET`（无 Auth）
- `DATABASE_URL`（无 DB）
- 微信/支付宝支付（阶段 2）
- AI / OSS / 邮件（阶段 2+）

## 八、故障排查

| 现象 | 排查 |
|---|---|
| 部署后 404 | Zeabur Root Directory 设成 `web/` 不是根 |
| 首页显示 6 板块 | 缓存没刷新，强制刷新（Ctrl+Shift+R） |
| sitemap 404 | 确认 web/app/sitemap.ts 存在，NEXT_PUBLIC_SITE_URL 已设 |
| 文章 404 | 检查 web/content/kb/<category>/<slug>.mdx 文件存在 |
| 国内访问慢 | Zeabur 默认 CN 机房仍偶有波动，稳定后再迁国内云 |
