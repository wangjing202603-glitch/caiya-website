## L2 — 业务组件（自研）

### 2.1 `KbSidebar` — 知识库侧栏

- **位置**：KB 详情页左侧，`sticky top-16`
- **Props**：`categories: KbCategory[]`、`activeSlug: string`、`onNavigate?: (slug) => void`
- **行为**：
  - 树形展示，最多展开 2 级
  - 当前文章高亮（`brand-50` 背景 + `brand-500` 文字）
  - ≥ 1024 始终展开，< 1024 折叠为顶栏触发 Sheet
- **键盘**：←→ 折叠/展开，Enter 进入

### 2.2 `KbToc` — 文章目录

- **位置**：详情页右侧，`sticky top-16`
- **Props**：`headings: { depth, text, slug }[]`
- **行为**：
  - 自动从 MDX 抽 h2/h3
  - 滚动时高亮当前章节（IntersectionObserver）
  - < 1024 折叠为顶部 <details>
- **可访问性**：用 `<nav aria-label="文章目录">` 包裹

### 2.3 `KbCard` — 知识卡片

- **位置**：分类页 / 首页
- **Props**：`title`、`summary`、`href`、`tags?`、`updatedAt?`
- **视觉**：
  - 圆角 `radius-lg`，hover 阴影 `shadow-md` + 上移 2px
  - 标题用 `text-lg font-semibold`，2 行截断
  - 摘要 `text-sm text-ink-500`，3 行截断

### 2.4 `KbBreadcrumb` — 面包屑

- **位置**：详情页头部
- **Props**：`items: { label, href? }[]`
- **行为**：最后一项不可点击，span + `aria-current="page"`

### 2.5 `KbCallout` — 提示块

- **Props**：`type: "info" | "warning" | "danger" | "success"`、`title?`、`children`
- **视觉**：左边 4px 竖条 + 浅色背景 + 图标

### 2.6 `Paywall` — 会员拦截

- **位置**：会员内容上方
- **Props**：`requiredPlan: "member" | "pro"`、`previewLength?: number`
- **行为**：
  - 未登录 → 引导注册
  - 已登录无权限 → 显示定价 + "立即升级"按钮
- **预览**：可设置前 N 段为公开预览，超过则模糊

### 2.7 `ChatBubble` — AI 问答气泡

- **位置**：`/kb/search?mode=ai` 与右下角悬浮
- **Props**：`role: "user" | "assistant"`、`content`、`sources?`、`streaming?`
- **行为**：
  - 助手侧 markdown 渲染（含代码高亮、引用、表格）
  - 来源卡片可点击跳转 `/kb/...`
  - 流式输出时使用 Shiki 增量渲染（避免整段重排）

### 2.8 `PlanCard` — 套餐卡片

- **位置**：`/pricing`
- **Props**：`plan: Plan`、`currentPlanId?`、`onSelect`
- **视觉**：3 列网格；推荐套餐加 "最受欢迎" 徽章 + 边框 `brand-500`

### 2.9 `OrderItem` — 订单行

- **位置**：`/account/orders`
- **Props**：`order: Order`
- **状态机**：`pending / paid / refunded / expired / failed`，对应 Badge 颜色

### 2.10 `SearchBar` — 搜索框

- **位置**：顶部导航 + 搜索页头部
- **Props**：`mode: "search" | "ai"`（可切换）
- **行为**：
  - 输入防抖 300ms
  - 快捷键 `⌘K` / `Ctrl+K` 唤起命令面板
  - 历史搜索：本地最近 5 条

## 命名约定

- 文件名：kebab-case，如 `kb-sidebar.tsx`
- 默认导出：**禁止**（便于 tree-shaking）
- Props 类型：`{Component}Props`
- 显式标记 `"use client"`（RSC 默认服务端）

## 依赖锁定

- `lucide-react` 图标库
- `class-variance-authority` + `tailwind-merge` 样式变体
- `radix-ui` 行为原语
- 不引入：Material UI / Ant Design / Chakra（与 shadcn 冲突）

## 维护

- 新增组件 → 先在本文登记，标 `草案` / `稳定`
- 废弃 → 标 `deprecated: true`，保留 1 个大版本
- 修改公共组件 → 写 ADR（影响面评估）
