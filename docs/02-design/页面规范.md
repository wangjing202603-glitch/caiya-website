# 页面规范

> 最后更新：2026-07-02 · 维护人：@设计负责人
> 所有页面必须遵守本规范，新增页面先在这里登记。每个页面给出：目的、关键区块、组件清单、关键交互、可访问性要点、验收清单。

---

## 1. 首页 `/`

**目的**：30 秒内让访客搞懂"我们是谁、你能得到什么、怎么加入"。

**风格基调**（2026-07-02 决策）：参照 [starglowai.com](https://starglowai.com/) 的 `/join` 页面布局（12 周训练营 + 数字大字 + 训练主题 chips），用无衬线 + 暖琥珀主色统一视觉。

**关键区块**（自上而下）：

1. **Hero（双栏）**
   - 左侧：标签 `跃迁计划 · 2026 夏季`（font-mono）+ H1 + 副标题 + 主/次 CTA + 训练主题 chips
   - 右侧：4 个数字大字卡（实战手册数 / 周训练计划 / 大板块数 / 夏季首期）+ 装饰圆点 SVG
   - H1（如「用 AI 提效 80% 的财务工作」）≤ 24 字
   - 主 CTA：「继续学习」→ `/kb`；次 CTA：「查看会员方案」→ `/pricing`
2. **最近更新条**（左侧暖琥珀竖条 + 真实 `updatedAt` 日期 + 最新文章标题动态绑定，禁止硬编码）
3. **6 大板块 · 全场景覆盖**：板块 tag 导航（首项高亮），点入 `/kb/[category]`
4. **12 周训练计划**（4×3 网格，每卡含 WEEK 编号 + 主题标题；用 `animate-fade-in-up` 错峰进入）
5. **最近更新**：6 张 `KbCard` 网格（按 `updatedAt` 倒序）
6. **AI 问答 CTA**（横条）：图标 + 文案 + 「试一下」→ `/kb/search?mode=ai`
7. **底栏**

**组件**：`KbCard`、`Badge`、lucide 图标

**可访问性**：H1 唯一；所有图片有 `alt`；CTA 按钮文字清晰；色块对比度 ≥ 4.5:1

**验收清单**：
- [ ] 移动端 H1 字号 ≥ 30px
- [ ] 首屏不出现水平滚动
- [ ] 板块 tag 在 sm 断点正常 wrap
- [ ] 12 周网格在 sm/md/lg/xl 断点正确折叠（1→2→3→4 列）
- [ ] CTA 按钮键盘可达 + 焦点环可见
- [ ] Lighthouse 性能 ≥ 85
- [ ] **不允许有硬编码假数据**：所有日期、文章标题、计数必须从 `lib/kb.ts` 动态取

## 2. 知识库总览 `/kb`

**目的**：让访客快速进入分类或被最新内容吸引。

**关键区块**：

1. **Hero 简版**：标题"AI 财务知识库" + 简短描述 + `SearchBar`
2. **分类卡片网格**：6 张大卡片（分类名 + 描述 + 文章数 + 跳转）
3. **最近更新**：10 篇最新文章（列表形式）
4. **热门标签**：前 20 个 `tags`，点击筛到分类页

**组件**：`KbCard`、`SearchBar`、`Badge`

**验收清单**：
- [ ] 分类卡片数与 `_index.json` 完全一致
- [ ] "最近更新"按 `publishedAt` 降序
- [ ] 移动端分类卡片单列

---

## 3. 知识库分类 `/kb/[category]`

**目的**：列出该分类下所有文章。

**关键区块**（双栏）：

- 左：`KbSidebar`（分类树）
- 中：
  - 分类标题 + 描述
  - 子分类 / 标签筛选
  - 文章列表（`KbCard` 形式，按 `order` 升序 + `publishedAt` 降序）
  - 分页（每页 20 篇）

**组件**：`KbSidebar`、`KbCard`、`Badge`、`Pagination`

**验收清单**：
- [ ] 侧栏高亮当前分类
- [ ] URL 包含分类 slug，中文转拼音
- [ ] 空分类显示空态："该分类暂无内容"

## 4. 知识库详情 `/kb/[category]/[slug]`

**目的**：让读者专注阅读，同时能跳到相关章节与其他文章。

**关键区块**（三栏）：

- 左（≥ 1024）：`KbSidebar`
- 中：正文
  - `KbBreadcrumb`
  - 标题 + 元信息（作者、最后更新、阅读时长）
  - `KbCallout`（可选，Frontmatter `callout` 字段）
  - MDX 正文（标题 / 段落 / 列表 / 代码 / 表格 / 公式 / 图）
  - 文末"是否有用？"（👍👎 反馈，匿名）
  - "相关推荐"（同分类下 3 篇）
  - 评论（阶段 4 启用）
- 右（≥ 1024）：`KbToc`
- 移动端：顶栏抽屉 + 顶部 <details> 目录

**正文排版规则**：

- 段落：行高 1.8，段间距 24px
- H2：上下 32px 留白，字号 `text-2xl`，带锚点 #
- H3：上下 24px，字号 `text-xl`
- 引用块：左边 4px 竖条，背景 `ink-100`
- 代码块：右上角"复制"按钮，Shiki 主题
- 表格：横线分隔，无外框；表头加粗
- 图片：自动懒加载 + `loading="lazy"` + `decoding="async"`
- 公式：KaTeX，行内 `\(...\)`、行间 `$$...$$`

**会员内容（Paywall）**：

- Frontmatter `access: "member" | "pro"`
- 公开部分占全文 ≤ 40%，超过则触发 `Paywall` 模糊
- 付费/会员用户可看完整内容

**可访问性**：

- 标题层级严格 h1→h2→h3，不跳级
- 锚点链接：`#` 按钮出现在标题 hover 时
- 图片 `alt` 必填；纯装饰图 `alt=""`
- 颜色不是唯一信息载体（链接除了下划线还有颜色）

**验收清单**：
- [ ] 文章 H1 唯一且与 `<title>` 关联
- [ ] 移动端 TOC 折叠为 <details>
- [ ] 代码块一键复制可用
- [ ] "是否有用"反馈会写入后端
- [ ] 暗色模式无错位

## 5. 搜索 / AI 问答 `/kb/search`

**目的**：让"找资料"和"问问题"在一个入口完成。

**关键区块**：

1. `SearchBar`（顶部，模式切换 `search` / `ai`）
2. **搜索模式**：
   - 左侧：过滤（分类、标签、作者、更新时间）
   - 中部：结果列表（标题高亮、命中片段）
   - 分页（每页 10）
3. **AI 模式**：
   - 左侧：上下文设置（"只用公开内容 / 包含会员内容"）
   - 中部：对话流（`ChatBubble`）
   - 用户消息右对齐，助手左对齐
   - 每条助手消息后附"引用来源"卡片（最多 5 条）
   - 输入框含"使用次数：本月 X/20"提示（限流）

**组件**：`SearchBar`、`KbCard`、`ChatBubble`、`Badge`、`Pagination`

**可访问性**：

- 对话区用 `aria-live="polite"` 让屏幕阅读器朗读新消息
- 来源卡片键盘可达

**验收清单**：
- [ ] 模式切换不刷新页面（URL 改 query）
- [ ] 流式输出在弱网下不卡死（断点续传提示）
- [ ] 引用卡片点击跳转对应文章锚点
- [ ] 限流提示清晰

## 6. 会员定价 `/pricing`

**目的**：让访客在 30 秒内选好套餐并下单。

**关键区块**：

1. **标题**："选择适合你的会员" + 副标题
2. **PlanCard × 3**（免费 / 会员 / Pro）横向排列，移动端纵向
3. **功能对比表**（详细对比，折叠展开）
4. **常见问题**（Accordion，6~10 条）
5. **企业 / 团购咨询入口**

**组件**：`PlanCard`、`Accordion`、`Button`

**验收清单**：
- [ ] 推荐套餐视觉突出
- [ ] "立即开通"按钮 → 登录态判断：未登录跳注册，已登录跳支付
- [ ] 价格与 `Plan` 表完全一致

## 7. 账户中心 `/account/*`

### 7.1 资料 `/account/profile`

- 头像 / 昵称 / 邮箱 / 手机号
- 微信绑定状态
- 退出登录

### 7.2 订阅 `/account/billing`

- 当前套餐 + 到期日
- "续费" / "升级" / "取消订阅"
- 续费历史 `OrderItem` 列表

### 7.3 订单 `/account/orders`

- `OrderItem` 列表（按时间倒序）
- 单条可查看详情 / 申请发票

### 7.4 收藏 `/account/library`

- 收藏的文章 `KbCard` 网格
- 最近阅读（去重，最多 30 篇）

---

## 8. 鉴权页 `/auth/*`

- 极简单页（Logo + 居中卡片 + 暗色背景）
- 登录支持：邮箱 + 密码 / 邮箱验证码 / 微信扫码
- 注册只走邮箱验证码（避免密码管理）
- 重置密码走邮件链接，24 小时有效

**可访问性**：

- 错误信息用 `aria-describedby` 关联输入框
- 验证码倒计时有 `aria-live` 朗读

---

## 9. 错误页

- **404**：插画 + "这篇内容可能还没写好" + 推荐文章 + 搜索框
- **500**："服务开了小差" + 客服微信 + "返回首页"
- **会员过期**：插画 + "你的会员已到期" + 续费 CTA

---

## 10. 共用规范

- 所有页面：右上角"主题切换"+ 头像 / 登录按钮
- 所有页面：底部含"用户协议 / 隐私政策 / 备案号 / 公众号"
- 所有页面的 `<title>` 模板：`{页面标题} - AI 财务社群`
- 所有页面必须有 `lang="zh-CN"`
