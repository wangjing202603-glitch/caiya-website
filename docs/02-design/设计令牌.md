- 文字 vs 背景对比度**必须** ≥ 4.5:1（小字）/ 3:1（大字）

## 2. 字体

> 决策（2026-07-02）：整站统一使用 **Noto Sans SC**（无衬线、现代极简）。原衬线斜体方案（Source Han Serif SC + italic）已弃用，原因是与参考站气质不匹配。

### 2.1 字体栈

| 角色 | 栈 | 备选 |
|---|---|---|
| 主字体（标题/正文统一） | `var(--font-noto-sans-sc), "Noto Sans SC", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif` | 由 `next/font/google` 注入 `--font-noto-sans-sc` 变量 |
| 兜底衬线（MDX 引用 / blockquote 装饰） | `"Songti SC", "STSong", "SimSun", serif` | 极少使用 |
| 代码 | `"JetBrains Mono", "SF Mono", "Cascadia Code", Consolas, monospace` | — |

### 2.2 字号（type scale）

| Token | 尺寸 | 行高 | 用途 |
|---|---|---|---|
| `text-xs`   | 12 | 16 | 辅助 / 脚注 |
| `text-sm`   | 14 | 20 | 元数据 |
| `text-base` | 16 | 28 | 正文（移动） |
| `text-md`   | 17 | 30 | 正文（PC） |
| `text-lg`   | 20 | 32 | 小标题 |
| `text-xl`   | 24 | 36 | 二级标题 |
| `text-2xl`  | 30 | 40 | 一级标题 |
| `text-3xl`  | 36 | 44 | 页面标题 |
| `text-4xl`  | 48 | 56 | 营销 H1 |

### 2.3 字重

- 正文 400、强调 500、标题 600/700
- 中文标题最大 700（避免加粗到糊）
- **不再使用 italic**（移除原 h1/h2 的全局 `font-style: italic`）

## 8. 暗色 / 主题切换

> 决策（2026-07-02）：**单 amber 主题**（不再支持"信任蓝 / 沉稳绿 / 暖橙"切换），仅保留「亮 / 暗 / 跟随系统」三种模式。

- 使用 CSS 变量 + `[data-theme="amber"]` 选择器（整站唯一色彩）
- 切换由自定义 `ThemeProvider` 控制（`web/components/layout/theme-provider.tsx`），持久化到 `localStorage('theme')`
- 切换瞬间不允许出现"白闪"——`html.bg-ink-50` 提前设上
- `ThemeSwitcher` 只显示「浅色 / 深色 / 跟随系统」三个按钮

## 9. 实施落地（Tailwind 片段）

```ts
// tailwind.config.ts（节选，与代码对齐）
export default {
  theme: {
    extend: {
      colors: {
        // 品牌色由 globals.css 中的 --brand-* 变量驱动（HSL 阶梯），此处仅占位
        brand: { 50: 'hsl(33 100% 97%)', 500: 'hsl(33 95% 51%)', 700: 'hsl(33 85% 36%)' },
        accent: { 500: '#14B8A6' },
        ink: { 50: '#F8FAFC', 200: '#E2E8F0', 500: '#64748B', 900: '#0F172A' }
      },
      fontFamily: {
        // 默认走 Noto Sans SC（由 next/font 注入 --font-noto-sans-sc）
        sans: ['var(--font-noto-sans-sc)', '"Noto Sans SC"', '"PingFang SC"', 'sans-serif'],
        serif: ['"Songti SC"', '"STSong"', '"SimSun"', 'serif'],
        mono: ['"JetBrains Mono"', 'monospace']
      }
    }
  }
}
```
