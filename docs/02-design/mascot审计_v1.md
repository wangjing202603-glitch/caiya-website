> 审计对象：`content/assets/mascot/cai-xiao-zhi.svg`（V2 暖琥珀版）
> 审计时间：2026-07-08

## 第一部分 · 设计哲学重申（审计基准）

### Amber Clarity · 琥珀澄明

财芽的一切视觉决策，都建立在一组**暖中性色**上——纸白 `#FAFAF8`、墨黑 `#1C1A18`、灰文 `#6B6B6B`。在这片底上，只允许一种强调色存在：暖琥珀 `#F09A1A`。它是稀缺的、昂贵的，每次出现都携带信号意义。

形态要几何、要干脆。圆角是材质语言：4px 给按钮，8px 给卡片——**不超过 8px**。超过就是奶油甜点，不是财务工具。直角和小圆角的对比本身就是层级。

视觉层级靠**字重对比**承担 70%：H1 用 700，H2 用 600，正文 400。CTA 只有两种权重——主 CTA 实心琥珀 + 辉光阴影，次 CTA 描边。**绝不允许第三个 CTA 同台竞争**。

整站气质是**减法到极致的精工感**。参考 starglowai.com——极简、文字驱动、大量留白、一个主 CTA、**没有吉祥物**。每一个间距值都经过 painstaking attention。剩下的东西，每一个都必须配得上它的位置。

**核心张力判断**：Amber Clarity 是"几何精工的克制"，任何"圆润萌系"的具象角色都会稀释这种克制。这是审计的核心标尺。

## 第二部分 · 六项逐项审计

### 1. 色彩一致性 ⚠️ 部分贴合（实际 ~80%，非 95%）

README 自评 95% 偏高。独立核验 SVG 用色 vs 网站色板：

| mascot 用色 | 网站对应 | 判断 |
|---|---|---|
| `#F09A1A` 头部/手臂 | `--brand-500` | ✅ 精准 |
| `#F5AD3C` 身体 | hero 渐变起始 | ✅ 精准 |
| `#3D3B38` 手脚/耳朵 | `ink-700` | ✅ 精准 |
| `#FAFAF8` 面部 | `--background` | ✅ 精准 |
| `#F7F6F2` 腹部 | `--card` | ✅ 精准 |
| `#1C1A18` 眼睛 | `ink-900` | ✅ 精准 |
| **`#F0997B` 腮红** | **无对应** | ❌ 网站色板没有珊瑚粉 |
| **`#14B8A6` 计算器/电路** | `accent-500` 增长青 | ⚠️ 网站有此色但**首页/hero 从未使用**，mascot 大量用青色装饰，与"单色琥珀"哲学冲突 |
| **`#5EEAD4`/`#CCFBF1`** 浅青 | accent-300/100 | ⚠️ 同上，网站未实际使用 |

**问题**：单色琥珀哲学下，mascot 引入了**珊瑚粉 + 增长青**两个网站首页不用的色，破坏了"只允许一种强调色"的纪律。README 说匹配 95%，但首页实际从未出现青色/粉色，所以从"首页调性"看是 ~80%。

**修正**：腮红改 `#F5AD3C`（琥珀浅，低透明度）；计算器/电路装饰**全部砍掉或改琥珀色**。让 mascot 也遵守"单色琥珀"纪律。

### 2. 调性贴合 ❌ 不贴合（核心冲突）

这是最严重的问题。

- **网站气质**：Amber Clarity = 几何精工 + 克制 + 极简 + 文字驱动。参照 starglowai **没有吉祥物**。
- **mascot 气质**：圆润萌系机器人 + 大眼 + 腮红 + 蝴蝶结 + 持金币 + 天线 + 柱状图 + 计算器 = **高密度装饰的卡哇伊风格**。

两者**根本冲突**。Amber Clarity 的美在于"什么都不放"的克制；mascot 的美在于"什么都堆上"的热闘。把萌系机器人塞进极简首页，等于在侘寂茶室里放了个毛绒玩具。

starglowai 不用吉祥物是有道理的——它的信任感来自**内容的厚度 + 排版的精工**，不靠拟人化角色讨喜。财芽走同一条路，加 mascot 是**方向性回退**。

**修正**：mascot 不进首页 hero。如果要保留，只在 AI 问答对话框/空状态这类"需要人情味"的小场景用，且缩小到 80px 内。

### 3. 与 logo 风格一致 ❌ 不贴合

- **logo（财芽嫩芽）**：抽象几何，5 个 path，茎+两叶+芽头，琥珀填充+深棕描边。气质 = **精工、抽象、成人感**。
- **mascot（财小智）**：具象拟人，40+ 元素，圆润机器人+表情+配饰。气质 = **萌系、具象、儿童友好**。

两者**不是同一个设计语言**。logo 像一个律所/咨询公司的标志，mascot 像儿童教育 App 的吉祥物。同时出现，用户会困惑"这到底是个专业品牌还是个玩具品牌"。

**修正**：要么 mascot 几何化（向 logo 靠拢，去表情去配饰，只保留抽象机器人轮廓），要么 logo 萌化（不推荐，会毁掉精工感）。建议前者。

### 4. 专业 vs 萌系张力 ❌ 张力不合理

品牌人格：「专业而不端着：像一位资深财务经理在给你讲经验」。

- 资深财务经理的画像：干练、可信、有阅历、不卖萌。
- mascot 的画像：大眼+睫毛+腮红+蝴蝶结 = 萌妹/儿童。

**受众错位**：README 说目标受众是"以女性为主的中小企业财务"。但女性财务人要的不是"可爱"，是**"被专业地对待"**。把萌系吉祥物推给女性受众，反而传递"我觉得你需要被哄"——这是居高临下，不是亲和。

"不端着"的正确表达是**口语化的专业**（像静静的文章），不是"装可爱"。mascot 把"不端着"误解成了"萌"。

**修正**：去掉睫毛、缩小腮红、去蝴蝶结。让 mascot 显得"专注/利落"而非"卖萌"。或者干脆不要拟人表情，做成抽象 AI 符号。

### 5. 符号密度 ❌ 过载

数一下 mascot 传递信息的符号：

天线信号灯 / 屏幕脸 / 大眼+高光+睫毛 / 腮红 / 蝴蝶结 / 电路装饰 / ¥徽章 / 手持金币 / 浮动柱状图 / 浮动计算器 / 装饰星星 / 装饰圆点方块 = **12 类元素**。

frontend-design-audit 反模式明确："section 内 >5-7 个元素竞争就是杂乱"。mascot 单帧塞了 12 类。每个符号都在喊"我代表 AI/财务/财富/亲和/科技"，结果**什么都没说清**。

对比 logo：5 个元素，只说一件事（新芽 = 成长）。高下立判。

**修正**：砍到 ≤5 类。建议保留：天线（AI）+ 屏幕脸（数字）+ ¥徽章（财务）。砍掉：蝴蝶结、持金币、柱状图、计算器、电路、装饰星星圆点。

### 6. 应用场景 ⚠️ 部分贴合

- **首页 hero**：❌ 不适合。Hero 已是"12 周训练营 H1 + 双 CTA + 杂志卡"，视觉锚点是杂志卡。再塞 mascot（240-400px）会拥挤，且打破极简。
- **AI 问答头像**：✅ 适合。对话框需要"对话感"，mascot 头像（裁头部 80px）能用。
- **空状态**：⚠️ 可用但要简化。120px 内装饰元素要砍。
- **微信群头像**：✅ 适合。社交场景需要亲和。
- **会员欢迎页**：✅ 适合。低决策场景，mascot 陪伴无妨。

**结论**：mascot 适合**低决策、需人情味的辅助场景**，不适合**高决策、需专业感的主舞台**（首页 hero / 定价页 / 文章详情页）。

## 第三部分 · 贴合度总评

**色彩 ~80% | 调性 ~30% | logo 一致 ~20% | 人格 ~35% | 符号密度 ~25% | 场景 ~60%**

**综合贴合度：约 42%**

**一句话结论**：财小智是一个**自洽的萌系吉祥物**，但跟财芽网站的「Amber Clarity 几何精工」哲学**根本不在一个设计语言**——它更适合儿童教育或社交 App，不适合一个想做"资深财务经理"人设的知识付费品牌。

## 第四部分 · 三个最重要的修正动作

### P0 · 降级使用（不重做，先止血）

**mascot 不进首页 hero / 定价页 / 文章详情页**。只在 AI 问答头像、空状态、会员欢迎页、微信群头像这 4 个"辅助+人情味"场景用。这是零成本止损——首页调性立刻干净。

### P1 · 砍符号 + 去彩色（向 Amber Clarity 靠拢）

若要保留 mascot，做 V3 精简版：
- **砍到 5 元素**：天线 + 屏幕脸 + ¥徽章（留）；蝴蝶结/持金币/柱状图/计算器/电路/装饰星点（全砍）
- **去睫毛、缩腮红**：从"萌妹"改"专注"
- **单色化**：腮红改 `#F5AD3C`，增长青装饰全改琥珀色——遵守"只一种强调色"纪律
- **圆角收紧**：头部/身体 rx 从 52/72 降到 24/32，向网站"≤8px 圆角"靠拢（不严格 8px，但别这么圆）

### P2 · 决策：mascot vs 抽象符号（长期）

长期看，建议**用抽象 AI 符号替代拟人 mascot**。比如把 logo 的嫩芽 + 一个电路节点组合，做成"AI 芽"抽象图标——既保留品牌资产（嫩芽），又有 AI 感，且不破坏 Amber Clarity。拟人吉祥物对一个专业财经知识库是**调性负担**，不是资产。

## 第五部分 · 去/留决策建议

| 场景 | 建议 | 理由 |
|---|---|---|
| 首页 hero | ❌ **不用** | 破坏极简，与杂志卡争视觉 |
| 定价页 | ❌ **不用** | 决策场景要专业不要萌 |
| 文章详情页 | ❌ **不用** | 阅读场景要安静 |
| AI 问答头像 | ✅ **用**（裁头部 80px，V3 简化版） | 对话框需对话感 |
| 空状态插画 | ⚠️ **简化后用** | 120px 内，去装饰 |
| 会员欢迎页 | ✅ **用** | 低决策，陪伴感 |
| 微信群/机器人头像 | ✅ **用** | 社交场景需亲和 |
| 周边（贴纸/帆布袋） | ✅ **用** | 周边本来就是玩的 |

**核心判断**：财小智不是"不能用"，是"**不能放在主场**"。它适合做品牌的**社交面孔**（社群/客服/周边），不适合做**专业门面**（首页/定价/内容）。把它从主舞台撤到辅助位，调性问题立刻消失大半。
