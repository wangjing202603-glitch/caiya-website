# 部署

> 最后更新：2026-07-01 · 维护人：@运维负责人

## 1. 架构总览

```
            ┌──────────────┐
   HTTPS →  │   Vercel     │ ←── Next.js 应用（SSR/ISR/Edge）
            └──────┬───────┘
                   │
        ┌──────────┼──────────┐
        ▼          ▼          ▼
   ┌────────┐  ┌────────┐  ┌────────┐
   │ Neon   │  │ 阿里云 │  │ Sentry │
   │  PG    │  │  OSS   │  │        │
   └────────┘  └────────┘  └────────┘
        ▲
        │ (webhook)
   ┌────┴────┐
   │ 微信 /  │
   │ 支付宝  │
   └─────────┘
```

- **应用**：Vercel（海外访问友好，国内可考虑腾讯云 EdgeOne 加速，阶段 4 评估）
- **数据库**：Neon serverless PostgreSQL（启用 pgvector 扩展）
- **对象存储**：阿里云 OSS（国内）+ Vercel Blob（兜底，阶段 4 评估）
- **可观测**：Sentry（错误）+ Plausible（分析）
- **支付**：商户号在微信 / 支付宝开放平台

## 2. 环境

| 环境 | 域名 | 数据库 | 部署 |
|---|---|---|---|
| dev | localhost:3000 | 本地 Docker | 手动 |
| preview | `*.vercel.app` / `preview.aicaiwu.cn` | Neon preview 分支 | 每个 PR |
| staging | `staging.aicaiwu.cn` | Neon staging 分支 | 手动 promote |
| production | `aicaiwu.cn` | Neon production | main 合入后自动 |

## 3. CI/CD

### 3.1 GitHub Actions

- `ci.yml`：lint / typecheck / test / build
- `release.yml`：发版 + 打 tag + 触发 Vercel 生产部署
- `db-migrate.yml`：手动触发 `prisma migrate deploy`

### 3.2 Vercel

- 关联 GitHub
- 每次 PR → Preview
- `main` 合入 → Production
- 部署日志、构建产物 30 天可回看

## 4. 环境变量

- 全部走 Vercel Environment Variables
- 分环境管理：Development / Preview / Production
- 凭据轮换见 [`../03-rules/安全合规.md`](../03-rules/安全合规.md)
- 任何本地开发从 `.env.example` 复制 → `.env`

## 5. 部署流程

### 5.1 阶段 1（静态站）

1. PR 合入 `main` → Vercel 触发生产部署
2. 自动跑 `prisma generate`（不需要连接 DB）
3. 部署完成后 Vercel 通知 → 群内贴"已上线"
4. 主理人 5 分钟内 smoke test

### 5.2 阶段 2 起

1. PR 合入 `main` → 触发 Preview 部署 + 自动化 e2e
2. 预发验证：
   - 运营在 staging 走通"注册→下单→访问会员内容"全流程
3. 手动 "Promote to Production"
4. 主理人 5 分钟 smoke test
5. 30 分钟观察无异常 → 任务完成

## 6. 回滚

### 6.1 应用回滚

- Vercel Dashboard → Deployments → "Promote to Production" 选上一个版本
- 或 `vercel rollback`

### 6.2 数据库回滚

- 严格模式下 schema 变更不能"前进回滚"——用 `prisma migrate resolve` 标记 + 新迁移修复
- 数据回滚：用 Neon 时间点恢复（最多 7 天）

### 6.3 静态资源回滚

- OSS 启用版本控制
- 删错文件 → 用历史版本覆盖

## 7. 域名与备案

- 主域名：`aicaiwu.cn`
- 备案主体：与支付主体一致
- 备案号写在所有页面底栏
- DNS：阿里云 DNS

## 8. 边缘优化

- 国内访问 Vercel 慢 → 阶段 4 加 EdgeOne / 腾讯云 CDN
- 静态资源走 OSS + CDN
- 字体走 `next/font` 自托管

## 10. 速查

| 场景 | 操作 |
|---|---|
| 部署失败 | Vercel 日志 → 回滚到上一个绿色构建 |
| 性能问题 | 看 Vercel Analytics + Sentry 慢事务 |
| 数据库连接满 | 检查连接池 + Neon 控制台 |
| 域名解析异常 | 检查 DNS + 备案状态 |
