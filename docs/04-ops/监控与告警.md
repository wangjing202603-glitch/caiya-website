# 监控与告警

> 最后更新：2026-07-01 · 维护人：@运维负责人

## 1. 监控目标

- **可用性**：核心页面 P95 < 2s，错误率 < 0.5%
- **业务**：付费转化、会员续费率、AI 命中率
- **安全**：登录失败、API 异常调用、敏感操作

## 2. 工具

| 维度 | 工具 |
|---|---|
| 应用错误 | Sentry |
| 性能 | Vercel Analytics + Sentry Performance |
| 用户分析 | Plausible |
| 数据库 | Neon Metrics |
| 日志 | Vercel Runtime Logs + 阿里云 SLS（阶段 2） |
| 告警 | 飞书 / 钉钉 Webhook（阶段 1） |

## 3. 关键指标

### 3.1 基础设施

| 指标 | 阈值 | 告警级别 |
|---|---|---|
| 错误率（5xx） | > 0.5% 持续 5 分钟 | P2 |
| P95 响应时间 | > 3s 持续 10 分钟 | P2 |
| 部署失败 | 任何 | P1 |
| DB 连接数 | > 80% | P2 |
| Neon CPU | > 70% 持续 10 分钟 | P3 |

### 3.2 业务

| 指标 | 阈值 | 告警级别 |
|---|---|---|
| 注册转化率 | 日环比 -30% | P3 |
| 付费转化率 | 日环比 -50% | P2 |
| 支付成功率 | < 95% | P1 |
| webhook 处理失败率 | > 2% | P1 |
| AI 命中率 | < 0.7 | P3 |
| 退款笔数 / 订单 | > 5% | P3 |

### 3.3 安全

| 指标 | 阈值 | 告警级别 |
|---|---|---|
| 登录失败突增 | > 50/分钟/IP | P2 |
| 异常地区登录 | 任意 | P2 |
| 关键表 DELETE 频次 | > 10/小时 | P1 |
| 关键词命中 | 黑名单触发 | P2 |

## 4. 告警通道

- **P1**：电话（值班人）+ 飞书群 @主理人
- **P2**：飞书群 @值班
- **P3**：飞书群话题

值班表：`docs/04-ops/oncall-rotation.md`（阶段 1 末建立）

## 5. 看板

- Vercel Analytics：流量、Core Web Vitals
- Sentry：错误、慢事务
- Plausible：漏斗（注册 → 订阅 → 续费）
- 自建 Superset 看板：业务指标（阶段 2）

## 6. 日志规范

- 结构化 JSON
- 字段：`timestamp`, `level`, `service`, `traceId`, `userId?`, `path?`, `message`, `context`
- 敏感字段（身份证 / 银行卡 / 邮箱 / 手机号）脱敏
- 保留 90 天（Vercel 30 天 + 阿里云 SLS 90 天）

## 7. 演练

- 每月 1 次故障演练（chaos）
- 季度全链路压测
- 半年度灾难恢复演练

## 8. 速查

| 场景 | 操作 |
|---|---|
| 收到 P1 告警 | 5 分钟内 ack + 拉群处理 |
| 支付失败告警 | 立刻查 webhook 日志 + 商户后台 |
| 数据库慢查询 | `pg_stat_statements` + EXPLAIN |
| 用户反馈"网站打不开" | 看 Vercel Status + 国内访问延迟 |
