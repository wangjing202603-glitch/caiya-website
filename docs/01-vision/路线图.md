# 路线图

> 最后更新：2026-07-01 · 维护人：@主理人

我们把项目划分为 **5 个阶段**，每个阶段都有"可对外发布的产物"和"明确的退出标准"。当前在 **阶段 0**。

---

## 阶段 0 — 基建（本周，2026-07）

**目标**：把"游戏的规则"全部写好，让任何工程师/Agent 接手都能推进。

**交付**：

- ✅ `docs/` `memory/` `skills/` `templates/` 全部建立
- ✅ `content/kb/` 分类骨架
- ✅ Git 仓库初始化、`.gitignore` `.editorconfig` `.gitattributes`
- ✅ ADR-0001：技术栈选型

**退出标准**：

- 新加入的 Agent 读 `AGENTS.md` + `README.md` 后能 30 分钟内定位所需文档
- 任何阶段 1 的工作都能找到对应的"规则文件"

---

## 阶段 1 — MVP：可读的 KB 静态站（4~6 周，2026-08 中）

**目标**：让"会读"的人先来看，验证内容方向与 SEO。

**范围**：

- Next.js 14 工程初始化（App Router + TS + Tailwind + shadcn/ui）
- 设计令牌 + 基础组件（Button / Card / Sidebar / Toc / Search 框）
- MDX 渲染管线（remark/rehype + KaTeX + Mermaid + Shiki）
- 5 个分类的目录页 + 至少 30 篇示例文章
- `/` `/about` `/kb` `/kb/[category]/[slug]` 4 类页面
- Vercel 部署 + 自定义域名

**不在范围**：

- 登录、会员、支付、AI 问答

**退出标准**：

- 30 篇文章在 Vercel 上跑起来，PC/移动端均无错位
- Lighthouse 性能 ≥ 85、可访问性 ≥ 90
- 站内搜索可用（基础全文匹配，不要求语义）

---

## 阶段 2 — 会员与支付（4 周，2026-09 中）

**目标**：跑通"免费内容 → 付费会员"的主链路。

**范围**：

- Prisma + PostgreSQL + Auth.js
- 微信支付 V3 + 支付宝适配器
- 订单状态机 + Webhook 重试
- 会员中心、订阅状态、Paywall 组件
- 邮箱 + 短信验证码登录

**不在范围**：

- 后台 KB 编辑（继续用 Git）
- 退款争议自动处理（先人工介入）

**退出标准**：

- 真实用户可注册 → 下单 → 微信支付 → 会员内容解锁
- 5 个真实订单的支付/回调/对账无异常
- 7 天后无重复扣款 / 漏单

---

## 阶段 3 — AI 财务问答（3 周，2026-10 上）

**目标**：把"知识库"升级为"问答助理"。

**范围**：

- pgvector 扩展 + 嵌入任务（切块、向量化、写入）
- `/api/ai/chat` SSE 流式接口
- 前端 ChatBubble + 引用卡片 + 限流（免费 20/日，会员无限）
- 命中率人工评估（≥ 30 条 query 集）

**不在范围**：

- 多轮对话上下文管理（MVP 只做单轮）
- AI 自动写文章 / 自动评论

**退出标准**：

- 50 个真实 query 的命中率 ≥ 0.8
- 一次回答平均 < 4 秒返回首字
- 引用卡片点击率 ≥ 30%

---

## 阶段 4 — 增长与运营（持续，2026-10 起）

**目标**：让流量与留存滚起来。

**范围**：

- 邮件订阅（周报 + 新文章通知）
- 公众号联动（同步更新 + 短链追踪）
- SEO 加固：sitemap、JSON-LD 知识图谱、内链推荐
- Plausible 分析接入 + 漏斗看板
- 社群裂变：邀请码、推荐返佣

**退出标准**：

- 月自然搜索流量 ≥ 5 万 UV
- 周报打开率 ≥ 25%
- 会员推荐转化率 ≥ 8%

---

## 阶段 5 — 内容工业化（2027 H1）

**目标**：把"专家 + 编辑"模式工程化。

**范围**：

- 后台 KB 管理（Payload CMS 或自研）
- 选题 → 写作 → 评审 → 发布 的工作流平台
- 多媒体：短视频脚本、播客文字稿、直播课排期
- 数据中台：内容表现、会员行为、收入看板

**退出标准**：

- 单月可稳定产出 20 篇高质量文章
- 编辑/作者/审校三人协作无沟通成本

---

## 阶段对照表

| 阶段 | 周期 | 主交付 | 主指标 |
|---|---|---|---|
| 0 基建 | 1 周 | 系统文档 | 文档完整度 |

| 3 AI 问答 | 3 周 | RAG 助手 | 命中率 / 首字延迟 |
| 4 增长运营 | 持续 | 流量+留存 | UV / 留存率 |
| 5 内容工业化 | 半年 | 工作流平台 | 产能 / 自动化率 |

## 风险与回退

| 风险 | 触发条件 | 回退方案 |
|---|---|---|
| 微信支付申请不下来 | 4 周内未通过 | 临时只走支付宝；社区团购 + 手动开通 |
| 国内 LLM 召回率不足 | 命中率 < 0.6 | 退回关键字搜索 + 编辑人工精选 FAQ |
| SME 资源不足 | 月产 < 8 篇 | 暂缓原创，改为"政策解读 + 转载授权" |
| ICP 备案延迟 | 6 周未批 | 用 Vercel 临时域 `*.vercel.app` 跑 MVP |
