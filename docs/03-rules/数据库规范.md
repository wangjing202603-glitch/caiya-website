# 数据库规范

> 最后更新：2026-07-01 · 维护人：@工程负责人

## 1. 选型

- 主库：PostgreSQL 16+（启用 `pgvector` 扩展）
- ORM：Prisma
- 连接池：Neon serverless / PgBouncer（按部署平台二选一）
- 缓存：Redis（阶段 3 后引入，仅限限流计数 / 队列）

## 2. 命名

- 表名：`snake_case` 复数，例如 `kb_articles`
- 列名：`snake_case`
- 主键：`id`（cuid 或 uuid v7，不用自增 int）
- 外键：`<单数表名>_id`，例如 `user_id`
- 时间：`created_at`、`updated_at`、`deleted_at`（软删）
- 枚举：单数名词 + `_status` / `_type`

## 3. 必备列

每张业务表必须：

```prisma
id          String   @id @default(cuid())
createdAt   DateTime @default(now()) @map("created_at")
updatedAt   DateTime @updatedAt        @map("updated_at")
deletedAt   DateTime?                  @map("deleted_at")
```

软删统一在 Prisma 中间件里加 `where: { deletedAt: null }`。

## 4. 迁移

- 改 schema → 跑 `pnpm prisma migrate dev --name <描述>`
- 提交迁移文件到 `prisma/migrations/`
- 生产部署：CI 跑 `prisma migrate deploy`
- **禁止**手改 `migration.sql`；如有特殊需求写注释并在 PR 描述里说明

## 5. 危险操作

- DROP / TRUNCATE → 必须有备份 + 维护窗口
- 大表加列 → 用 `ALTER TABLE ... ADD COLUMN ... DEFAULT NULL` 后再补默认
- 改列类型 → 拆为"加新列 → 同步双写 → 切读 → 删旧列"
- 涉及 ≥ 100 万行的更新 → 写脚本 + 限速 + 监控

## 6. 索引

- WHERE / JOIN / ORDER BY 出现的列才加索引
- 组合索引按"区分度高 → 低"顺序
- 文本搜索：`tsvector` 列 + GIN 索引
- 向量：`pgvector` + HNSW（阶段 3）
- 索引命名：`idx_<表>_<列>` 唯一索引 `uniq_<表>_<列>`

## 7. 关联与外键

- 强制外键（避免孤儿数据）
- 一对多：子表加 `*_id`
- 多对多：中间表 `<a>_<b>`，复合主键
- 多态关联用 JSON 列 + 触发器校验（不推荐；能用单表就单表）

## 8. 软删与归档

- 默认软删
- 30 天以上的软删数据可归档到 `*_archive` 表
- 永久删除需维护者双人审批 + 备份

## 9. 审计

- 关键表（`users` `orders` `memberships` `kb_articles` `audit_logs`）增删改写 `audit_logs`
- 字段：`actor_id`、`action`、`target_type`、`target_id`、`payload(jsonb)`、`created_at`
- 审计表不进业务查询，永不删

## 10. 敏感字段

- 身份证 / 银行卡 / 手机号：列名 + `_enc`，应用层加密（AES-256-GCM）
- 邮箱：明文存但加 hash 索引用于查重
- 支付凭据：**不落库**，仅在内存中处理
- 日志：**禁止**打印身份证 / 银行卡完整号

## 11. 性能

- 单表 > 1000 万行：考虑分区（按时间 / 类别）
- 慢查询 > 200ms：必须在 PR 中说明
- 大 JSON：放 JSONB，不要放 TEXT
- 计数器表（如 view_count）：用单独的小表 + 异步聚合

## 12. 备份

- 全量每日 + 增量每 6 小时
- 备份保留 30 天
- 季度恢复演练
- 详见 [`../04-ops/备份与恢复.md`](../04-ops/备份与恢复.md)

## 13. 凭据与访问

- 应用账号：最小权限（CRUD 业务表，不允许 DROP / GRANT）
- 迁移账号：受限 + 仅 CI 使用
- 运维账号：DBA 持有，本地 1Password
- 任何账号密码 / 连接串 → 不入 Git，用 `.env` + Vercel/Neon 控制台

## 14. 速查

| 场景 | 规则 |
|---|---|
| 加列 | 默认 NULL，回填完再加 NOT NULL |
| 加索引 | `CONCURRENTLY` 避免锁表 |
| 改 enum | 用新 enum + 迁移，**不删旧值** |
| 删数据 | 软删 + 二次确认 |
| 跨库查询 | 禁止；同步走应用层 |
