# 内容审核规范

> 最后更新：2026-07-01 · 维护人：@内容负责人

## 1. 范围

需要审核的内容：

- AI 问答回复（特别是会员公开发布的场景）
- 用户评论（KB 文章底部）
- 用户提问（即将上线的"问专家"功能）
- 知识库投稿（团队外投稿）

## 2. AI 问答

### 2.1 前置护栏

系统提示词中强制要求：

- 不得承诺收益、节税金额、避税方案
- 不得给出"针对个人 / 企业"的具体筹划
- 不得传播未经公开的监管口径、内部信息
- 不确定时建议"咨询持证专业人士 / 当地税务机关"
- 引用文件、政策必须能追到原文链接

### 2.2 关键词过滤

阶段 1 起启用关键词黑白名单（`config/keywords.ts`）。

**黑名单（命中即拒答）**：

- 涉政 / 涉黄 / 涉暴 / 涉恐
- 明确"避税 / 逃税 / 内部通道"
- "保证收益""稳赚""翻倍"

**灰名单（命中转人工或加提示）**：

- 涉及"如何规避 / 怎么少交"
- 涉及具体公司 / 个人姓名
- 涉及"未公开"信息

### 2.3 命中后处理

- 黑名单：直接拒答，返回固定话术 + 客服入口
- 灰名单：附加免责声明，标记"建议咨询专业人士"
- 关键词命中 + 答案异常短 → 转人工

### 2.4 复审与抽样

- 每日随机抽样 5% 的 AI 回答人工复审
- 用户点 👎 的回答全部进入复审队列
- 复审记录写 `audit_logs`
- 严重问题 → 关键词库更新

## 3. 用户评论 / 提问

### 3.1 提交前

- 客户端用关键词预过滤
- 长度限制：评论 5~500 字
- 同一用户 1 分钟内最多 3 条

### 3.2 发布状态

- `pending`：待审核（默认）
- `approved`：通过
- `rejected`：拒绝（带原因）
- `hidden`：已隐藏（违规后）

### 3.3 审核流

1. 提交 → `pending`
2. 自动审核：
   - 黑名单 → `rejected`
   - 灰名单 → `pending` + 高优先级
   - 正常 → `pending`
3. 人工审核（每天 2 次统一处理）：
   - `pending` 内容进入后台
   - 通过 / 拒绝 + 原因
4. 通过后 `approved` → 对外可见
5. 通知用户审核结果（站内信）

### 3.4 举报

- 用户可在内容下方点"举报"
- 举报分类：广告 / 违法 / 人身攻击 / 与主题无关 / 其他
- 24 小时内响应
- 3 次举报 → 自动隐藏 + 进审核队列

## 4. 团队外投稿

### 4.1 流程

1. 投稿 → 创建 `submission` 工单
2. 维护者初筛（与社群方向是否一致）
3. 通过 → 走 [`../02-design/内容样式指南.md`](../02-design/内容样式指南.md) 的写作流程
4. SME 评审 + 编辑复核
5. 发布时标注"投稿"+"原作者"

### 4.2 协议

- 投稿时勾选协议：CC BY-NC-SA 4.0
- 支付稿酬的稿件，附独立协议

## 5. 工具

| 工具 | 用途 |
|---|---|
| 阿里云内容安全 | 文本 / 图片违规检测 |
| 微信开放内容 API | 兜底 |
| 自研关键词 | 快速拦截 |

> 工具是辅助，**不替代**人工抽检。

## 6. 应急

- 接到监管 / 用户投诉 → 24 小时内下架 + 内部审计
- 出现严重违规 → 关闭该用户 + 通知法务
- 月度违规报告 → 法务 + 主理人

## 7. 速查

| 场景 | 规则 |
|---|---|
| 评论发布 | 默认 `pending` |
| 敏感词命中 | 黑名单拒答 / 灰名单转人工 |
| 举报 | 24 小时响应 |
| 团队外投稿 | 走完整写作流程 + 标"投稿" |
