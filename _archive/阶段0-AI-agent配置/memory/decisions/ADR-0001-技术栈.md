# ADR-0001：技术栈选型

> 状态：已接受 · 2026-07-01 · 决策人：@主理人 + @工程负责人

## 背景

我们要做一个中文 AI 财务知识库 + 会员订阅 + AI 问答的全栈产品。需要在 **3 个月内**跑通 MVP（KB 静态站 → 会员支付 → AI 问答）。

约束：

- 团队小（2~3 人）
- 国内部署 / 国内合规 / 国内支付
- 需要 SEO 友好（知识库核心流量来自搜索）
- 后期会引入 AI 检索（RAG），需要 PG 的全文搜索 + 向量能力

## 备选方案

### 框架

| 方案 | 优势 | 劣势 | 结论 |
|---|---|---|---|
| **Next.js 14（App Router）** | 生态最大；RSC + ISR 适合 KB；Vercel 一键部署 | 边缘在国内访问慢 | ✅ **采用** |
| Nuxt 3 | 国内团队熟悉 | 生态比 Next 弱 | ❌ |
| Astro | 静态优先，性能最好 | 复杂交互弱 | ❌（V2 再评估） |
| Remix | 数据加载干净 | 生态仍小 | ❌ |

### 数据库

| 方案 | 优势 | 劣势 | 结论 |
|---|---|---|---|
| **PostgreSQL 16 + Prisma + pgvector** | 同时满足事务 + 全文 + 向量；Neon serverless 免运维 | 需启用扩展 | ✅ **采用** |
| MySQL | 国内 DBA 多 | 不支持 pgvector | ❌ |
| MongoDB | 灵活 | 不擅长关系 / 全文 | ❌ |
| Supabase | 全托管 | 数据出境顾虑 | ❌ |

### 认证

| 方案 | 优势 | 劣势 | 结论 |
|---|---|---|---|
| **Auth.js (NextAuth v5)** | 开源、自托管、支持邮箱 / 微信 / 手机号 | 配置略复杂 | ✅ **采用** |
| Clerk | 体验最好 | 数据出境 + 国内访问 | ❌ |
| Supabase Auth | 全托管 | 同上 | ❌ |

### 支付

| 方案 | 优势 | 劣势 | 结论 |
|---|---|---|---|
| **微信支付 V3 + 支付宝** | 国内主体唯一选择 | 商户申请周期长 | ✅ **采用** |
| Stripe | 海外 | 国内主体不友好 | ❌ |
| 虎皮椒 / Payjs | 接入快 | 合规 / 资金风险 | ❌ |

### UI

| 方案 | 优势 | 劣势 | 结论 |
|---|---|---|---|
| **Tailwind + shadcn/ui + Radix** | 与"克制的留白"风格匹配；可定制 | 学习曲线 | ✅ **采用** |
| MUI / Ant Design | 现成 | 视觉风格不匹配 | ❌ |
| Arco Design | 字节出品 | 视觉偏 SaaS | ❌ |

### AI

| 方案 | 优势 | 劣势 | 结论 |
|---|---|---|---|
| **OpenAI 兼容 API（DeepSeek/智谱/通义 任选）** | 灵活切换；价格灵活 | 需自评效果 | ✅ **采用** |
| 单一 OpenAI | 效果稳 | 国内访问 + 政策风险 | ❌ |
| 单一国产 LLM | 合规稳 | 锁定风险 | ❌ |

### 内容管理

| 方案 | 优势 | 劣势 | 结论 |
|---|---|---|---|
| **MDX + Git** | 工程师 / 编辑协作好；版本管理 | 非技术人员门槛高 | ✅ **采用（MVP）** |
| Payload CMS | 后台友好 | 部署 + 维护成本 | ❌（V2 评估） |
| Strapi | 同上 | 同上 | ❌ |

## 决定

- 前端：Next.js 14 (App Router) + TypeScript + Tailwind + shadcn/ui
- 后端：Next.js API Routes + tRPC（部分）
- 数据库：PostgreSQL 16 + Prisma + pgvector（Neon 托管）
- 认证：Auth.js v5（邮箱 / 微信 / 手机号）
- 支付：微信支付 V3 + 支付宝
- AI：OpenAI 兼容 API（默认 DeepSeek）
- 内容：MDX（Git 管理，阶段 5 评估 CMS）
- 部署：Vercel + Neon + 阿里云 OSS

## 影响

- 工程师招聘：TypeScript / React / Next.js 优先
- 编辑工作流：需要懂 Git + Markdown（或培训）
- 国内访问：阶段 4 评估 CDN 加速
- 数据合规：所有数据落境内（Neon 海外机房 + OSS 阿里云）
