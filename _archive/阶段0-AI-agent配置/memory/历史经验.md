## 常见"坑"预登记（提前预警）

> 这些还没踩到，但根据同类项目经验提前写在这里，提醒团队规避。

### 技术

- **Vercel 国内访问慢**：晚上 8~11 点高峰延迟 1s+。提前规划 EdgeOne / CDN。
- **Neon 免费版冷启动**：5 分钟后第一次查询慢。可用"keep-alive"或升级。
- **微信支付 V3 验签**：必须用最新平台证书，旧的会过期导致失败。建议每月校验。
- **AI 流式输出被 CDN 缓存**：用 `Cache-Control: no-store` + 关闭 Cloudflare 缓存（如果启用）。
- **MDX 注入风险**：用户内容（评论、搜索词）放进 MDX 渲染 → 必修 rehype-sanitize。

### 业务

- **"AI 全能"陷阱**：会员期待过高反而流失。需在 onboarding 明确"AI 是助手不是答案"。
- **政策过时**：税率、申报口径变了没及时更新 → 用户按旧文章操作被罚。**必须有"30 天核验"机制**。
- **过度承诺**：写"学会能省 N 万"被截图传播 → 引流效果有但合规风险大。统一话术"参考 + 个案咨询"。

### 运营

- **首月流量低**：知识库 SEO 至少 3~6 个月起效，需用公众号 + 微信群冷启动。
- **付费转化低**：免费内容太多导致"够用就行"。需做"AI 问答深度版"作为付费钩子。

### 合规

- **"内容仅供学习参考"声明**：必须在 AI 问答 + 文章首屏出现，不写在底部"没人看"。
- **支付主体与开票主体不一致**：开票被税务机关质疑。务必一致。
