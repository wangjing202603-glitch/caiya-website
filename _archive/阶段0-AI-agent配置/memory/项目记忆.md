## 1. 一句话

我们做 **AI × 财务/税务/合规** 的中文知识社群，参考 [starglowai.com/kb](https://starglowai.com/kb) 的视觉风格 + 国内合规要求 + AI 问答能力。

## 2. 关键决策（摘要）

完整 ADR 见 `memory/decisions/`。这里只放"为什么"和"被否掉的方案"。

| 主题 | 决定 | 否决方案 | 原因 |
|---|---|---|---|
| 框架 | Next.js 14 App Router | Nuxt / Remix / Astro | 生态最广，国内团队熟悉 |
| UI | Tailwind + shadcn/ui | MUI / Ant Design | 与"克制的留白"风格匹配 |
| 数据库 | PostgreSQL + Prisma | MySQL / Mongo | 需要 pgvector + 全文搜索 |
| 认证 | Auth.js v5 | Clerk / Supabase Auth | 自托管 + 国内手机号支持 |
| 支付 | 微信 V3 + 支付宝 | Stripe | 国内主体 |
| AI | OpenAI 兼容 API | 单一供应商 | 灵活切换 DeepSeek / 智谱 / 通义 |
| 内容 | MDX + Git | Headless CMS | 适合工程师 / 编辑协作 + 版本管理 |
| 部署 | Vercel + Neon | 自建 K8s | 团队规模小，少运维 |
| 字体 | Source Han Serif + Inter | 全思源黑体 | 标题衬线更有"专业可信"感 |
