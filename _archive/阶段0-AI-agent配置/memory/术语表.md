## 1. 财务 / 税务

| 术语 | 英文 / 缩写 | 释义 | 备注 |
|---|---|---|---|
| 增值税 | VAT / Value Added Tax | 对商品 / 服务增值额征收的税 | 中国主要流转税之一 |
| 企业所得税 | EIT / Corporate Income Tax | 对企业利润征收的税 | 25% 基本税率；小型微利有优惠 |
| 个人所得税 | IIT / Individual Income Tax | 对个人取得的应税所得征收的税 | 综合与分类相结合 |
| 小规模纳税人 | Small-scale Taxpayer | 年销售额 ≤ 500 万的增值税纳税人 | 简易计税，3% / 1% 征收率 |
| 一般纳税人 | General Taxpayer | 年销售额 > 500 万或主动登记 | 一般计税 |
| 加计扣除 | Super Deduction | 实际支出基础上按比例额外扣除 | 如研发费用 100% 加计 |
| 留抵退税 | VAT Credit Refund | 增值税进项大于销项时退付 | 2022 年起大规模实施 |
| 汇算清缴 | Annual Tax Settlement | 年度企业所得税 / 个税结算 | 5 月 31 日前完成 |
| 发票 | Fapiao | 中国税务发票 | 区分普票 / 专票 / 电子发票 |
| UKey / 税控盘 | Tax Control Device | 开具发票的硬件 | 航天信息 / 百旺 |
| 税收洼地 | Tax Haven (China) | 区域性税收优惠地区 | 合规使用，避免"违规返还" |
| 两账合一 | Two Books Integration | 内账外账合并 | 监管禁止，企业应"一账为准" |
| 金税四期 | Golden Tax Phase IV | 智慧税务系统 | 强化"以票控税"到"以数控税" |
| 小微企业 | Small and Micro Enterprise | 工信部划型标准 | 享受多项税收优惠 |

## 4. 易混词

| 正确 | 错误 | 原因 |
|---|---|---|
| 会计 | 会记 | 常见错别字 |
| 账本 | 帐本 | 财务场景用"账" |
| 增值税 | 增殖税 | 增殖 = 增殖，多用于生物 |
| 缴纳 | 上缴 | 缴纳更口语；"上缴"偏国家财政 |
| 微信支付 | 微信钱包 | 商户收款用"微信支付" |
| 个税 | 个人税 | 简称用"个税" |
| AI 助理 | AI 助手 | 团队内部统一"AI 助理" |

## 5. 标点与排版

- 中文：全角标点（，。：；！？""''（））
- 英文 / 数字：半角标点
- 数字与中文之间留 1 个空格：`1 个、¥99`
- 引用政策：`《财政部 税务总局公告 2023 年第 X 号》`
- 引用文件标题：双引号 `"..."`，外加书名号
- 强调用「」作为中文引号
