## 二、设计理念

财小智是一个融合 **AI 科技感** 与 **财务专业度** 的温暖圆润角色，V2 版全面对齐网站暖琥珀设计系统：

### 1. 品牌一致性（V2 核心改进）
- 主色调从冷蓝色系 → **暖琥珀色系**，与网站 `#F09A1A` 品牌色完全统一
- 中性色使用网站 ink 暖中性系列（`#FAFAF8` / `#F7F6F2` / `#1C1A18` / `#3D3B38`）
- 辅助色使用网站增长青 `#14B8A6`，替代 V1 的科技绿
- 色彩匹配度从 V1 的 ~15% 提升至 ~95%

### 2. 女性友好设计（V2 核心改进）
- **暖色调**：琥珀主色温暖亲切，替代冷蓝色的理性距离感
- **圆润造型**：头部 rx=52、身体 rx=72，全面增大圆角，软化工业感
- **放大亲和力细节**：
  - 眼睛增大（r=18），添加双高光点 + 睫毛
  - 腮红增大 50%（rx=15, ry=10），提高不透明度至 0.6
  - 蝴蝶结增大，添加暗色阴影层次
  - 微笑弧度加宽加柔

### 3. AI 科技感（保留）
- 机器人形态 + 天线信号灯 → AI 智能体
- 面部屏幕（暖米白底）→ 数字化、智能化
- 机身电路装饰（增长青）→ 科技基因
- 侧面"耳朵"旋钮 → 可交互、可调优

### 4. 财务专业度（保留）
- 胸前 ¥ 徽章 → 财务核心标识
- 手持金币 → 财富管理
- 蝴蝶结 → 专业着装礼仪，但不过分严肃
- 琥珀主色 → 信任、温暖、金融行业暖色系

## 五、使用场景

### 推荐使用
- 网站首页 hero 区右侧 / 左侧陪伴
- AI 问答助手对话框头像
- 会员欢迎页引导角色
- 知识库空状态插画
- 社群微信群头像 / 机器人头像
- 周边物料（贴纸、帆布袋、鼠标垫）

### 尺寸建议
| 场景 | 建议尺寸 | 说明 |
|---|---|---|
| 网站首页 | 240×240px ~ 400×400px | 保留浮动装饰 |
| 助手头像 | 80×80px ~ 120×120px | 裁切头部即可 |
| 空状态 | 120×120px ~ 200×200px | 可去掉装饰元素 |
| 周边 | 矢量无损缩放 | SVG 格式 |

### 使用边界（主舞台 vs 辅助场景）⚠️ 重要

> 依据：[mascot审计_v1.md](../../docs/02-design/mascot审计_v1.md)（贴合度 ~42%，萌系气质与 Amber Clarity 几何精工冲突）

财小智是**社交面孔**，不是**专业门面**。只用在低决策、需人情味的辅助场景：

| ❌ 不进（专业门面） | ✅ 进（社交面孔） |
|---|---|
| 首页 hero | AI 问答头像（裁头部 80px） |
| 定价页 | 空状态插画（120px，去装饰） |
| 文章详情页 | 会员欢迎页 |
| 板块卡片 | 微信群/机器人头像 |
| | 周边（贴纸/帆布袋/鼠标垫） |

**理由**：首页/定价/详情要 Amber Clarity 的极简精工感，萌系机器人会稀释专业可信。社群/客服/周边需要亲和力，mascot 在那里才是资产。

### 禁止事项
- ❌ 不要改变角色的核心配色方案（必须使用网站暖琥珀色板）
- ❌ 不要将角色拉伸变形（保持宽高比）
- ❌ 不要在角色上叠加滤镜/特效破坏原有风格
- ❌ 不要移除 ¥ 徽章（核心品牌符号）
- ❌ 不要回退到 V1 的冷蓝色系

## 六、表情扩展方向（后续迭代）

财小智的面部屏幕设计支持后续扩展不同表情：

| 表情 | 场景 | 改动点 |
|---|---|---|
| 微笑（默认） | 首页、欢迎页 | 当前设计 |
| 思考 | AI 问答加载中 | 眼睛变为 `··`，嘴变为 `○` |
| 惊喜 | 答案出炉 | 眼睛变大，嘴变为 `O` |
| 担心 | 数据待核验 | 眉毛增加 `╲╱`，嘴变为 `∼` |
| 点赞 | 用户完成操作 | 眼睛变为 `^^`，嘴变为 `D` |

## 七、技术规格

- **格式**：SVG（矢量，无损缩放）
- **画布**：680 × 640
- **色深**：sRGB
- **字体**：sans-serif（系统默认无衬线）
- **文件大小**：约 5KB（极轻量，适合 Web 加载）
- **色彩来源**：`web/app/globals.css` + `web/tailwind.config.ts`

## 八、设计审查记录

### V1 → V2 审查（2026-07-08）

**审查背景**：用户提出两个维度审查 — 1) 配色与网站调性是否搭；2) 目标受众主要是女性，是否符合女性审美

### V2 → V2.1 审计修订（2026-07-08）

**审计背景**：canvas-design skill 对照 Amber Clarity 设计哲学做 6 维度审计，综合贴合度 ~42%。

**核心结论**：萌系圆润机器人 与 几何精工哲学 调性冲突；女性受众要"被专业对待"而非"被哄"。

**V2.1 修订**：不重做 mascot，新增「使用边界」规范——mascot 降级为社交面孔（AI 头像/空状态/社群/周边），不进专业门面（首页 hero/定价/详情）。详见第五节「使用边界」。

**V1 问题**：
1. 配色严重不匹配：网站使用暖琥珀 `#F09A1A` 单一色板（CSS 注释「告别冷 slate 蓝灰」），人偶却以冷蓝 `#185FA5` 为主色，匹配度仅 ~15%
2. 女性受众适配度偏低：蓝色偏理性/男性化；矩形机器人造型偏工业感；亲和力细节比例太小

**V2 改进**：
1. 全面对齐网站暖琥珀色板，色彩匹配度提升至 ~95%
2. 放大女性友好细节：大眼睛+高光+睫毛、大腮红、大蝴蝶结、更圆润造型
3. 保留 AI 科技感和财务符号，但全部转换为暖色调
